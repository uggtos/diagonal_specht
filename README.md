# diagonal_specht
Run diagonal_specht.sage script on SageMath in order to verify the computational steps of the preprint "Specht varieties of the diagonal action"

It was designed f and run for SageMath 10.6, release date 2025-03-31, and Python 3.12.3

The file hook_11111_m2_output.txt shows the output when we run the script for lambda=(1,1,1,1,1) and m=2.

The file hook_2111_m4_output.txt shows the output when we run the script for lambda=(2,1,1,1) and m=4.

The file hook_3111_m3_output.txt shows the output when we run the script for lambda=(3,1,1,1) and m=3.

The file hook_4111_m2_output.txt shows the output when we run the script for lambda=(4,1,1,1) and m=2.

The file 514.output.txt shows the output when we run the script to verify Lemma 5.14
